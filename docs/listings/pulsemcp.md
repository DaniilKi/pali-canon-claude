# PulseMCP

PulseMCP (https://www.pulsemcp.com) is a directory and weekly newsletter about MCP servers.

**Status (checked 1 November 2026):** its submit page (https://www.pulsemcp.com/submit) says it is not taking new submissions. It asks authors to publish to the official MCP Registry instead and says it will pick listings up from there.

## Steps

1. Publish to the official registry first ([mcp-registry.md](mcp-registry.md)).
2. A few weeks later, search https://www.pulsemcp.com/servers for "Pali Canon".
3. If the submit page has reopened, submit with the [shared facts](README.md#shared-facts-use-the-same-words-everywhere) and the repository URL https://github.com/DaniilKi/pali-canon-claude.
