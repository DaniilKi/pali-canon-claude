# awesome-mcp-servers

https://github.com/punkpeye/awesome-mcp-servers is the best-known list of MCP servers on GitHub. Additions are pull requests that add one line to its `README.md`. The rules are in its [CONTRIBUTING.md](https://github.com/punkpeye/awesome-mcp-servers/blob/main/CONTRIBUTING.md): one server per line, alphabetical order within the section, a short accurate description.

## Where it goes

Section **🎨 Art & Culture** (`#art-and-culture`), where the Bible and Quran servers are listed. In alphabetical order the line goes just before `DataCraftsmanAU/vineverse-mcp`. (The other Tipiṭaka server is under Research; Art & Culture sits next to the other scriptures.)

Legend symbols used: 📇 JavaScript/TypeScript code, 🏠 runs locally, ☁️ also reaches online sources (English translations and the dictionary), 🍎 🪟 🐧 macOS, Windows, Linux.

## Steps (a maintainer does these)

1. Fork https://github.com/punkpeye/awesome-mcp-servers and create a branch, for example `add-pali-canon`.
2. Add the line in the Art & Culture section, in alphabetical order.
3. Open a pull request titled `Add Pali Canon (Theravāda scripture) server`, with a one-sentence description and a link to this repository.

The list's contributing guide offers a fast track for pull requests opened by automated agents. A maintainer opens this one, so it does not apply.
