# Hands-on acceptance for the seven-source intake

Record the exact commit, device/OS/browser, assistive technology and result.
Use synthetic notes. Automated viewport/touch/keyboard and axe results are
separate evidence from these hands-on checks.

## Phone

1. Open the reader for the first time and find the Apadāna collection.
2. Open tha-ap423 and explicitly request its Walters English source. Check the
   separate chapter heading, all note links, attribution and licence information.
3. Open tha-ap428:its nine publisher stanzas must retain the ten-VRI-stanza
   qualification. Open tha-ap429/431 and check combined local verse labels.
4. Each new source fits one native page. Check that the final words are visible
   and no unnecessary Next control appears.
5. Make a synthetic draft, shift focus to its input during delayed reading,
   navigate away and reopen. Confirm recoverable local text and intentional focus.

## Tablet and keyboard

1. Read with increased text size, both themes and changed orientation.
2. Tab through source selection, notes, bookmark/export and return controls.
3. Open earlier saved Pāli and English citations. Preserve their exact source
   positions through export and preview/restore; do not silently migrate ambiguity.
4. Open older tha-ap414/publisher 412. Follow its actual 6,000→1,546 continuation
   and copied citation, including focus after Next.

## Human screen reader and signed-in host

Use actual VoiceOver, NVDA or an equivalent to check title/source announcements,
loading/error feedback, note return, reading order and control names.
Record pronunciation and language-handling problems; an axe scan cannot settle them.
In an authorized signed-in assistant host, verify actual v53 resource loading,
explicit English consent, source pins, citations and notes. Standalone browser
tests do not establish host cache, bridge or permission behavior.

## Offline boundary

Distinguish external-internet loss with a local backend still reachable from
loss of the backend itself. Bundled Pāli is available to the backend offline;
the browser has no promised first-run disconnected installation, download/PWA
or account-sync behavior. Personal notes remain local to that browser unless
the user deliberately exports them. Do not mark unperformed device or host tests
as passed.
