# Frozen-DD candidate-pair replay

This is a source-only model, not a call to the parallels builder or current application. Inputs are the exact DD compressed canonical0f9 bytes and independently presealed ten full metadata replacements yielding f3b. All61 source books remain identical. FrozenDD canon/editions/shared source bytes are checked against the original Git-export manifest; only the finite pure renderer, page-label helpers, folding,53-bit FNV hash and default parameters are extracted. Eligibility, document frequency, stock filtering and candidate membership are independently expressed in PURE_STAGE123_MODEL.mjs. No current candidate parallels object, observed counter or final edges feed this model.

Stage3 candidate membership has a simple equivalence: a pair exists iff two distinct eligible documents have at least one accepted rare8-word-shingle occurrence in common. Multiplicity, segment positions and positionSets cannot change that existential statement. The model retains each occurrence when counting stock skips, then deduplicates accepted documentIDs per hash for stage3. This preserves the exact candidate pairSET, while deliberately not running the later filtering/scoring stages. DocumentIDs are unique (independently checked on original8544 records), so frozen loader's first-ID Map and the model's Map agree. It excludes shared owners and fully resolvable grouped ranges exactly as DD; it does not invent a duplicate-span filter.

Both phases have8246 documents,1145439 unique8-word hashes,110726 accepted rare hashes,25574 stock-shingle occurrence skips,1817325 total8-word occurrences,2158845 five-word occurrences and2749745 word occurrences. Raw sources are unchanged; five complete opening stanzas are reassigned to their correct adjacent owner. Candidate pairs independently derive12642→12639, with FIVE removed and TWO added pairs, not an unexplained count adjustment. Full pair lists and their SHA256s are sealed beside the report; per-UID neighbor-set deltas and all10 changed document statistics are recorded.

The candidate set is a prefilter. Frozen later code rejects overlap/same-method pairs, then requires30 shared words with20 consecutive, or at least12 with short-text coverage, and at least2 sufficiently rare words. An8-word candidate alone implies none of these. Therefore changing candidate membership does not by itself imply final-edge or citation changes. This model does not claim to have independently executed final filtering. The source test must require every final shared link, citation, score, source record and other JSON field to remain exactly the frozenDD object, allowing only canonical input checksum and the independently modeled candidate count.
