# Seven Itivuttaka range bindings: attribution audit (D202)

All seven screening leads were reproduced as **incorrect ordinary single-text
bindings**. A distinctive quotation from a later section could be reported under
the first discourse's ID. We replaced four bindings with explicit shared pages
and withheld three. Every former owner retains its independent DT translation.
No Pāli wording was changed or reconstructed.

## Reproduction and limits

[Before](../evidence/iti-attribution-before.json): manually selected distinctive
wording from the second explicit publisher section was verified as present there
and absent from the first section after normalization. Baseline seven-owner
bindings were restored in isolated memory, with other data unchanged. The real
source-level `verifyQuote` function, exact requested owner/version and complete
fixed publisher snapshot returned `found`, similarity1, with the wrong first
owner ID for all seven cases.

[After](../evidence/iti-attribution-after.json): identical quotation digests and
snapshots produce only null-ID **page-level** results for the four approved
shared pages, with explicit consent and false individual/whole-unit alignment.
The other three exact versions fail before fetch, without substituting DT.
Receipts contain metadata/digests, not quoted English. These are source-level
production-function checks with fixed local providers, not installed-MCP or
live deployed before/after incidents. They do not prove every possible quotation
is unique.

Installed-package tests separately cover real metadata, overlapping source
choices, missing consent, source/notice drift and all six current withheld
bindings through metadata, URL resolution, retrieval and quotation checks.
Synthetic fixture scopes are isolated from real shared declarations. Real
metadata assertions still preserve the exact ordinary/source choices. Mixed
verification is batched within existing public input/result limits; no API cap
was raised.

## Rights and runtime boundaries

Ṭhānissaro's accepted Ones/Twos/Fours pages retain ©2001 CC BY-NC4.0 notices,
ATI revision30 November2013. Ireland's Ones retains the complete ©1997 BPS
notice, ATI revision24 November2013: copies free of charge, derivative/source
attribution, complete licence and ≤50 reprints. **BPS is not CC.** Supporting
that explicitly reviewed metadata label does not approve other BPS pages.
Mandatory ATI notice hashes, source-text pins, source-commit/root pins, exact
consent, contiguity and32-member limits remain unchanged. No English bodies are
bundled or archived. Generic publisher-page reading remains separate from a
canonical individual translation claim.

The existing reader paginates long English pages at6,000 characters. Live
acceptance now follows every continuation, checks exact version/offset/scope and
prefix arguments, reconstructs the full text hash, and retains complete notices
on every fragment. Choice selectors distinguish publisher references when two
shared versions concern the same subject. The production UI was unchanged.
