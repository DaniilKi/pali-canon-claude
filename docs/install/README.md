# Install guides

Pick the app you use. Every option runs the same server with the same tools. You need no account or key for Pali Canon itself.

| App | Guide | What you need |
|---|---|---|
| Claude Desktop | [Install in Claude Desktop](claude-desktop.md) | Nothing else: the extension file contains everything |
| Claude Code | [Install in Claude Code](claude-code.md) | Node.js 20 or newer |
| Codex (CLI and app) | [Use it in Codex](codex.md) | Node.js 20 or newer |
| Gemini CLI and Antigravity CLI | [Install in Gemini CLI](gemini.md) | Node.js 20 or newer |
| Cursor, VS Code, Windsurf, Zed, Cline, Goose | [Install in editors and agent apps](ide.md) | Node.js 20 or newer |
| LM Studio, Open WebUI, Ollama and other local apps | [Use it with local AI models](local-clients.md) | Node.js 20 or newer |

A hosted web version, for Claude on the web and on phones, is built but not online yet. ChatGPT support is planned; see the [roadmap](../roadmap.md).

Once it is installed, try the [examples](../examples.md).
