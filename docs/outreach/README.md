# Permission letters

Letters to the people and organisations whose work this project uses, or would like to use. Each one explains the project, how their work is or would be used, our attribution and non-commercial safeguards, and the exact permission we are asking for.

**None of these letters has been sent.** Sending a message on the project's behalf needs the maintainer, so the maintainer sends each one (see [How to send one](#how-to-send-one) below). Until a source replies, we keep to its published terms, and anything that needs permission is built without content (see the [source library](../sources.md)).

Contact routes were checked on each organisation's own public website on 1 November 2026. Where a site blocked the check, the letter says so and gives the contact page to confirm in a browser. We never guess an email address.

## How to send one

1. Open the letter and read "Before sending".
2. Fill in your name and reply-to address, then send it (or submit the contact form) yourself.
3. Change its status above to "sent, <date>".
4. When a reply arrives, change the status to "replied, <date>", and record what was agreed in [docs/sources.md](../sources.md). A "no" is recorded too, and the source becomes link-only.
